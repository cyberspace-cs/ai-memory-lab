# MemEngine 代码实现方案 · nano-memory v0

> 目标：~1000 行纯标准库可跑全链路（离线可测），每个模块对应设计方案一节。
> 上游对照：每模块头部 docstring 标注【抄谁】与 fork 内源码路径。

## 模块分解与接口

| 模块 | 对应设计 | 关键接口 | 依赖 |
|---|---|---|---|
| `schema.py` | §2 数据模型 | `MemoryItem/SourceRef/FactCandidate/ResolutionLog` dataclass + JSON | 无 |
| `provenance.py` | §2/⑤ | `EpisodeStore.add(text,ts,origin) -> Episode`；`validate_source()` | schema |
| `resolve.py` | §4 四档裁决 | `Resolver.resolve(new, conflicts) -> Resolution(op, evidence, item)` | schema |
| `graph.py` | §2/③ | `EntityGraph.add_triple/neighbors/canonical(alias)` | 无 |
| `extract.py` | §1① 三级提取 | `BaseExtractor.extract(episode) -> [FactCandidate]`；`LLMExtractor`（OpenAI 兼容，可选）/`RuleExtractor`/`DictExtractor` | 无（LLM 可选） |
| `store.py` | §3 | `MemoryStore.upsert/find_conflicts/history/save/load` | schema |
| `lifecycle.py` | §3/⑥ | `MemEngine.add_episode/query/decay/export_audit`（facade） | 全部 |
| `retrieve.py` | §5 | `Retriever.query(q,k,include_history)` BM25+图扩展+RRF | store/graph |

## 实现顺序（TDD）

1. schema + provenance（不变量 1 测试）
2. resolve 四档 + 不变量 2/3/4 测试
3. graph 归一化 + 邻居测试
4. extract（Dict 跑测试；Rule 处理 `X 的 predicate 是 object`/`X works at Y` 模式；LLM 留桩）
5. store + lifecycle 串联（换城市/换手机/改偏好反转语料）
6. retrieve BM25(bigram 中文) + 引用链测试

## 里程碑

- **v0（本次）**：全链路离线可跑，tests 全绿（3 处反转语料验收）
- **v1**：sqlite 持久化 + LLMExtractor 接 dsh/DeepSeek + mem0 prompt 对照改写
- **v2**：sqlite-vec 向量召回 + FalkorDB 图后端 + graphiti `edge_operations` 对照
- **v3**：AuditScope 事件单语料评测 + 导出 RFT 标注格式

## 运行

```bash
cd ai-memory-lab && python3 -m pytest tests/ -q   # 或 python3 -m unittest discover tests
```
零第三方依赖（pytest 可选，用 unittest 也能跑）。
